# コンバイン収穫ゲーム 設計書（v0.1）

- 種類：1 人用のブラウザゲーム（PC のみ、キーボード＋マウス）。Three.js。
- 方針：**ゲーム性寄り**。機械の形と動き、「タンクが満杯だと刈れない」「カートは刈った跡しか走れない」といった関係は本物に合わせ、時間と量は遊びやすさに合わせて縮める。
- 土台：3D 再現（`docs/design.md`、M0〜M6）の部品・見た目・圃場・作物フローをそのまま使う。
- レビュー：§14（v0.1 への指摘と対応）。

---

## 1. コンセプト

**制限時間内に、畑の端のトラックへ運び込んだ小麦の量を競う。**

コンバインはプレイヤーが運転する。グレインカート（トラクタが引く穀物の荷車）は AI が動かす。プレイヤーの腕の見せどころは次の 3 つ。

1. **刈り方**：速く走るほど多く刈れるが、脱穀部の能力を超えると取りこぼしが増える。収量の高い場所では速度を落とす。
2. **回収のタイミング**：タンクが満杯になると、刈った小麦は入らずに失われる。満杯になる前にカートを呼び、並走させて排出する。
3. **回り方**：カートは立っている小麦の中を走れない。排出オーガは機体の左にある。左側が刈り跡になるように回らないと、カートが横に来られない。

同じシード（マップの種）なら同じ畑になるので、友達と同じマップで点数を比べられる。

## 2. 1 ラウンドの流れ

1. タイトル画面で難易度とマップ（今日のマップ／シード入力／ランダム）を選ぶ。
2. 開始。コンバインは枕地（畑の外周の刈り終えた帯）に、カートはトラックの横にいる。
3. 制限時間（ふつう 5 分）のあいだ刈り、カートを呼んで排出し、カートがトラックへ運ぶ。
4. 時間切れで刈り取りは止まる。**トラックに入った量だけが得点**。タンクやカートに残った分は数えない。そのため、終盤にカートを早めに帰すかどうかも判断になる。
5. 結果画面：得点、ランク、損失の内訳、ベスト記録、シードのコピー。

## 3. 操作（PC）

| キー | 操作 |
|---|---|
| W / ↑ | 加速（前進） |
| S / ↓ | 減速。止まってから押し続けると後退（最大 4 km/h） |
| A / D、← / → | ハンドル（後輪操舵。離すと中央へ戻る） |
| Space | ヘッダを上げる／下げる |
| Q | 排出オーガを振り出す／格納する |
| E | カートを呼ぶ／帰す |
| C | カメラの切り替え（追従・高い追従・真上・自由） |
| Tab | ミニマップの拡大 |
| Esc | 一時停止（メニュー） |
| R | やり直し（一時停止中） |

- マウス：自由カメラでドラッグ回転、ホイールで拡大。
- 速度は W/S を押している間だけ変わる（クルーズ制御）。手を離しても速度を保つので、刈っている間はハンドルに集中できる。

## 4. ゲームの規則

### 4.1 コンバイン
| 項目 | 値 | 本物との関係 |
|---|---|---|
| 刈幅 | 12.19 m（40 ft） | 本物どおり |
| 速度 | 前進 0〜12 km/h、後退 0〜4 km/h | 作業速度の範囲は本物どおり |
| 加速・減速 | 1.0 m/s²・2.0 m/s² | ゲーム用 |
| ハンドル | 後輪の切れ角は最大 32°、45°/s で動く | 最小旋回半径 6.0 m は本物どおり。**後ろが外へ振れる** |
| ヘッダの上げ下げ | 1.0 秒 | ゲーム用（本物は約 3 秒） |
| 排出オーガ | 振り出し 2.0 秒 | ゲーム用（本物は約 8 秒） |

- **刈る**：ヘッダを下げて走ると、刈刃が通ったセルの小麦を刈る（M6 の判定をそのまま使う）。
- **押し倒す**：次のどれかで、立っている小麦は倒れて失われる。
  - ヘッダを上げたまま小麦の上を走る。
  - 車輪や本体が刈っていない小麦の上を通る（後退中や急旋回で後ろが振れたとき）。
- **ぶつかる**：障害物（電柱・岩・木）やカートに当たると止まり、2 秒動けない。「衝突」として記録する。

### 4.2 取りこぼし（脱穀部の負荷）
- 負荷率 ＝ そのときの投入量 ÷ ロータの能力。計算は M6 と同じだが、**量はゲームの倍率（§5）を掛ける前の値**で行う。そのため上限は本物と同じく、標準の収量で約 5.5 km/h になる。
- 取りこぼし率 ＝ 0（負荷率 ≤ 1）、2.0 ×（負荷率 − 1）（上限 60 %）。
  - 例：標準の収量で 6 km/h なら負荷率 1.09 で 18 % を失う。面積は 2 割増えるので、得はほぼない。
  - 収量が 3 割高い場所を 5 km/h で刈ると、負荷率 1.18 で 36 % を失う。速度を落とすのが正解になる。
- 画面の「負荷メーター」は緑・黄（90 % 以上）・赤（100 % 以上）で表示する。

### 4.3 タンクと排出
- タンクが満杯の間に刈った小麦は**入らずに失われる**（「あふれ」として記録）。コンバインは走り続けられるので、止まるかどうかはプレイヤーが決める。
- 70 % と 90 % で警告音と表示を出す。
- 排出オーガを振り出し、スパウト（先端）が**カートの荷台の真上**にあるときだけ穀粒が流れる。
  - ふつう・かんたん：カートが下にいなければ自動で止まる。
  - むずかしい：カートがいなくても流れ、地面にこぼれる（「こぼし」として記録）。

### 4.4 グレインカート（AI）
| 状態 | 動き |
|---|---|
| 待機 | トラックの横で止まっている |
| 向かう | E で呼ぶと、通れるところを通ってコンバインの左側へ向かう |
| 並走 | スパウトの真下に荷台が来るように速度と向きを合わせる |
| 帰る | カートが満杯になるか E で帰すと、トラックへ戻る |
| 荷下ろし | トラックに移す（16 秒）。終わると待機に戻る |

- **通れるところ**：立っている小麦、障害物、水たまりから一定の距離がある場所だけ。つまり刈り跡と枕地。経路は 1 m 格子で探す（§8.3）。
- **左側に通り道がない**とき（左側がまだ刈っていない小麦）は、いちばん近い通れる場所で待ち、画面に「左側に通り道がありません」と出す。
- 急に曲がったり止まったりすると、カートは追従しきれずに離れる。そのとき、スパウトが荷台から外れれば排出は止まる。
- 「かんたん」では、タンクが 70 % になると自動で呼ぶ。

### 4.5 トラック
- 畑の端の道に止まっている。容量に上限はない（満杯になると次のトラックに入れ替わる演出だけにする）。
- **ここに入った量が得点**。

## 5. バランス表（ゲームの値）

時間の短い 1 ラウンド（5 分）の中で、タンクの出し入れを 2〜3 回させるために、穀粒の量を大きくする。

| 項目 | ゲームの値 | 本物の値 | 意図 |
|---|---|---|---|
| 穀粒の倍率 | ×15（表示する重さにも掛ける） | ― | 標準の速さで刈り続けて**約 90 秒で満杯** |
| タンク容量 | 10.6 t | 10.6 t（400 bu） | 本物どおり |
| 標準の収量 | 4.5 t/ha × 15 | 4.5 t/ha | ― |
| コンバインの排出 | 600 kg/s（満杯から 18 秒） | 116 kg/s（91 秒） | 並走の時間を短くする。刈りながら排出しても減っていく |
| カートの容量 | 32 t（タンク 3 杯分） | 1,000〜2,500 bu（27〜68 t） | 本物の小さめの型 |
| カートの速さ | 18 km/h（刈り跡・枕地）。並走中はコンバインに合わせる | 15〜25 km/h | ― |
| カートからトラックへ | 2,000 kg/s（32 t で 16 秒） | 500〜1,000 bu/分（14〜27 t/分） | 待ち時間を短くする |
| 制限時間 | かんたん 6 分、ふつう・むずかしい 5 分 | ― | ― |

**見込み**（ふつう、100 m の行程）
- 1 行程は刈り 72 秒＋旋回 20 秒。5 分で約 3 行程、刈る時間は計 200 秒ほど。
- 刈れる量は約 23 t（タンク 2 杯強）。カートは 1 往復で間に合う。
- 畑の広さ（0.6〜1.2 ha）は 5 分で刈り切れない大きさにする。得点は「どれだけむだなく刈れたか」で決まる。

## 6. マップの自動生成

シード（文字列）から、決まった手順で畑を作る。同じシードなら必ず同じ畑になる。

| 要素 | 作り方 |
|---|---|
| 畑の形 | 長方形・L 字・台形・角の欠けた長方形から選び、大きさを 80〜140 m × 50〜90 m で決める（0.6〜1.2 ha） |
| 枕地 | 畑の外周 25 m は刈り終えた帯（旋回とカートの通り道） |
| トラック | 畑の 1 辺に沿った道に止める |
| 収量 | なめらかなゆらぎ（±25 %）＋収量の高い場所 2〜4 か所（＋30〜50 %）。ミニマップに薄く色で出す |
| 障害物 | 電柱（半径 0.3 m）・岩（0.6 m）・立ち木（2 m）。畑の中に 0〜6 個 |
| 倒れた小麦（むずかしい） | 1〜3 か所。4 km/h を超えて刈ると 30 % を失う |
| 水たまり（むずかしい） | 1〜2 か所。小麦がなく、コンバインとカートは半分の速さになる |

**生成の検査**（作れなかったらシードを 1 つずらして作り直す）
- トラックから枕地の全周へ、カートが通れること。
- 障害物どうし、障害物と畑の縁・トラックの間に 8 m 以上あること。
- 基準のボット（§9）が、標準の範囲の点数を取れること。

「今日のマップ」は日付（例：2026-10-24）をシードにする。

## 7. 画面

### 7.1 プレイ中
| 場所 | 表示 |
|---|---|
| 上中央 | 残り時間、得点（トラックに入った量） |
| 左下 | 速度、ヘッダの状態、負荷メーター |
| 右下 | タンクの量（警告色）、排出の状態、カートの状態（待機・向かっている（到着まで ○ 秒）・並走中・帰っている）とカートの量 |
| 右上 | ミニマップ：畑・刈った所・障害物・コンバイン・カート・トラック・カートの経路 |
| 中央 | 短いお知らせ（「タンク 90 %」「左側に通り道がありません」「衝突」） |

- **ガイドライン**（かんたん・ふつう、切り替え可）：直前の行程と 0.2 m 重なる次の行程の線を地面に描く。本物の自動操舵のライトバーにあたる。
- カメラは「追従」が基本。後ろ上から見下ろし、少し遅れてついてくる。

### 7.2 タイトル・一時停止・結果
- **タイトル**：難易度、マップ（今日のマップ／シード入力／ランダム）、操作説明、ベスト記録。
- **結果**：
  - 得点（t）とランク：基準のボットの点数に対する割合で、S ≥ 100 %、A ≥ 85 %、B ≥ 70 %、C。
  - 内訳：刈った量、あふれ、取りこぼし、こぼし、押し倒し、衝突の回数、カートを待った時間、刈った面積。
  - 「同じマップでもう一度」と、シードと得点のコピー（友達と比べる用）。

## 8. しくみ（コード構成）

### 8.1 方針
- **シミュレーションと描画を分ける**。シミュレーションは 60 Hz の固定刻みで、乱数はシードから作る。同じシードと同じ入力なら同じ得点になり、Vitest で確かめられる。
- 入口を分ける。いまの 3D 再現は `index.html`、ゲームは `game.html`（Vite の複数ページ）。1 ファイルにまとめたページもそれぞれ作る。

### 8.2 ディレクトリ
| 場所 | 内容 | 既存から使うもの |
|---|---|---|
| `src/game/balance.ts` | §5 の値 | ― |
| `src/game/map.ts` | マップの自動生成と検査 | `field.ts` のゆらぎ・乱数 |
| `src/game/sim/combine.ts` | コンバインの運動（後輪操舵）、ヘッダ・オーガの動き、衝突 | `path.ts` の操舵の式、`kinematics.ts` |
| `src/game/sim/harvest.ts` | 刈り取り、押し倒し、取りこぼし、タンク | `field.ts` の sweepCut・flattenUnder、`harvest.ts` の能力 |
| `src/game/sim/cart.ts` | カートの AI（状態・経路・並走） | ― |
| `src/game/sim/grid.ts` | 通れる場所の格子と経路探索（A*） | ― |
| `src/game/sim/game.ts` | 1 ラウンド（時間、得点、記録） | ― |
| `src/game/bot.ts` | 基準のボット（自動運転） | `path.ts`（U ターン）、`scenario.ts` の操作の規則 |
| `src/game/input.ts` | キー入力 → 操作 | ― |
| `src/game/ui/` | HUD、ミニマップ（2D canvas）、タイトル・結果画面 | ― |
| `src/game/view/` | カート・トラクタ・トラック・障害物・ガイドライン | `buildModel`、`Animator`、`FlowView`、`FieldView` |

### 8.3 カートの経路
- 1 m 格子で「通れる」を決める。カートの半幅 1.6 m ＋ 余裕 0.6 m の範囲に、立っている小麦・障害物・水たまりがない格子。
- 呼ばれたとき、2 秒ごと、進めなくなったときに A* で経路を作り直す。目標は「スパウトの真下の点」。行けなければ、そこにいちばん近い通れる格子へ行く。
- 経路は追従制御（pure pursuit、最小半径 5 m）でなぞる。並走の区間は、目標点との前後・左右のずれを PD 制御で詰める。

### 8.4 圃場のセル
- ゲームのセルは **0.5 m**（M6 は 0.25 m）。畑が広くなっても描く株の数を 6 万以下に抑えるため。株の見た目は 2 倍の大きさで描く。
- 畑の形の外側のセルは「小麦なし」（枕地）。障害物と水たまりのセルも「小麦なし」にする。

### 8.5 性能の目標
| 項目 | 目標 |
|---|---|
| fps | 中くらいの GPU（1080p）で 60 fps、内蔵 GPU で 30 fps 以上 |
| 三角形 | 150 万以下（株を描く「詳細」表示）。「軽量」表示も残す |
| シミュレーション | 1 刻み 0.3 ms 以下（カートの経路探索は 2 秒に 1 回、5 ms 以下） |

## 9. 基準のボット
- マップを作るたびに、自動運転でそのマップを 1 回遊ばせ、その点数を「基準」にする。
- 動き：トラックに近い辺から、左側が刈り跡になる向きで往復する。負荷率 95 % になる速度で刈る。タンクが 70 % で呼び、カートが満杯か残り 40 秒で帰す。
- 使い道：ランク（§7.2）、マップの検査（§6）、バランスの自動テスト（§10）。
- ボットの点数は画面に出す前に計算する（1 回 0.5 秒以内）。

## 10. テスト
| テスト | 確かめること |
|---|---|
| 決定性 | 同じシードと同じ入力の記録なら、同じ得点・同じ畑の状態になる |
| マップ | 1,000 個のシードで、検査（§6）を満たす畑が作れる。トラックから枕地へ通れる |
| カート | 立っている小麦・障害物の上を通らない。行けないときは近くで待つ。並走中、スパウトが荷台の上にある時間が 9 割以上（まっすぐ走っているとき） |
| 規則 | 満杯の間に刈った分は得点にならない。トラックに入った量だけが得点。負荷率と取りこぼし率の式 |
| バランス | 標準マップで、ボットの得点が 20〜26 t。ボットより遅い（4 km/h）・速すぎる（7 km/h）運転は、ボットより点が低い |
| 画面（e2e） | タイトル → プレイ → 結果まで進む。シェーダのエラーがない |
