# 大型コンバイン 3D再現 設計書（v0.1 ドラフト）

- 対象：米国型の大型普通型コンバイン（Class 8〜9 相当、単一アキシャルロータ機）
- 実装：Three.js（ブラウザ）
- 資料：`docs/research/01〜04`（パーツ別の調査結果と出典URL）
- レビュー：`docs/review.md`

---

## 1. 目的とスコープ

### 1.1 目的
大型コンバインの**外観**と**内部の作物処理の流れ**を、ブラウザで回転・分解・断面表示しながら理解できる3Dモデルを作ります。見た目のリアルさよりも「各パーツの形・位置・動きが実機に対して破綻していないこと」を優先します。

### 1.2 スコープ

| 区分 | 含める | 含めない（将来課題） |
|---|---|---|
| 機体 | 単一アキシャルロータ機 1機種（汎用デザイン） | ツインロータ／ハイブリッド／コンベンショナル（§11 で拡張方針のみ） |
| ヘッダ | ドレーパーヘッダ 40ft（既定）、コーンヘッド 12条（切替） | オーガプラットフォーム、ヘッダトレーラ |
| 走行 | ホイール（前デュアル無し） | クローラ仕様、物理エンジンによる走行 |
| 動き | 回転・往復・昇降・展開などの運動学的アニメーション | 作物の物理シミュレーション（粒子は「それらしく」流すだけ） |
| 表示 | 外観／X線（透過）／断面／分解／作物フロー | VR、モバイル最適化（動作はするが目標外） |

### 1.3 ブランドの扱い
実在メーカーのロゴ・商標・固有の配色の組み合わせは使いません。参考にした機種の**寸法とメカニズム**は使いますが、塗装は架空の配色（既定：本体「ハーベストオレンジ #D9822B」＋フレーム「チャコール #2E3236」＋ヘッダ同色）とし、`livery` 設定で差し替えられるようにします。

## 3. 座標系・単位

- 単位：**メートル**、角度はラジアン（設定ファイル上は度で書き、読み込み時に変換）
- **右手系**：`+X = 前進方向`、`+Y = 上`、`+Z = 機体の右側`
  - 注意：資料04 は「z は左が正」としていますが、x前・y上の右手系では +z は右になります。設計ではこちらに統一します（`docs/review.md` R-01）。
- **原点**：前車軸中心の真下の地面、機体中心線上
- 「左」＝ −Z ＝ 乗降ラダーと排出オーガがある側（オペレータから見て左）

## 6. 動き（運動学）

### 6.1 状態モデル
すべての動きは1つの `MachineState` から決めます（UI はこの値を変えるだけ）。

```ts
interface MachineState {
  engineOn: boolean;
  separatorOn: boolean;   // 脱穀部（ロータ・ファン・シュー・チョッパ）
  headerOn: boolean;      // ヘッダとフィーダ
  unloadOn: boolean;      // 排出オーガの回転と穀粒の流出
  groundSpeed: number;    // km/h（0〜12、収穫時 5〜8 を想定）
  headerHeight: number;   // 0..1（フィーダピボットの角度に写像）
  reelHeight: number;     // 0..1
  steerAngle: number;     // deg（後輪、±45）
  augerDeploy: number;    // 0..1（0=格納、1=展開）
  tankFlaps: number;      // 0..1
  tankFill: number;       // 0..1（穀粒の山の高さ）
  playbackScale: number;  // 表示用の回転減速率（§6.3）
}
```

`augerDeploy`, `tankFlaps`, `headerHeight` などは目標値への**一次遅れ（ダンピング付き補間）**で動かし、油圧の「じわっと動く」感じを出します。

### 6.3 高速回転の見せ方（ストロボ対策）
60 fps で 1,000 rpm（16.7 Hz）の部品を描くと、1フレームで100°回り、逆回転や静止に見えます（エイリアシング）。そこで：

1. 表示回転数＝`min(実rpm × playbackScale, 上限 120 rpm)`。既定 `playbackScale` は部品ごとに表の「表示既定値」になるよう設定。
2. 「実速モード」を選んだときは、回転体にモーションブラー風の**半透明ディスク**（回転面を覆ううっすらした円盤）を重ねて、高速回転していることを示す。
3. UI に「表示は実速の約 1/20 です」と明示する（教育用途で誤解を防ぐ）。

### 6.4 リンク機構
- **フィーダ昇降シリンダ**：シリンダ本体は Chassis 側のアンカー点、ロッド先端はフィーダ側のアンカー点。毎フレーム両端点のワールド座標を取り、本体を lookAt＋ロッドの長さを `distance − bodyLength` で伸縮。
- **後輪操舵**：左右同角（アッカーマンは省略。将来課題）。
- **ヘッダのリール**：リール昇降アームのピボット回転と、リール前後位置のスライドを独立パラメータに。

## 7. 作物フロー（粒子）表現

教育用途の目玉です。物理シミュレーションはせず、**あらかじめ決めた経路に沿って粒子を流す**方式にします。

### 7.1 流れの種類と経路

| 流れ | 色 | 経路（区間ごとに CatmullRomCurve3 または専用の運動則） |
|---|---|---|
| 穀物（刈った作物） | 黄土 | ヘッダ前縁 → ドレーパー（横→中央） → フィードドラム → フィーダ（斜め上） → ロータ入口 |
| わら | 薄茶 | ロータ周りのらせん（半径 0.42 m、9 周、ピッチ = 長さ / 9） → ビータ → チョッパ → 扇形散布（後方 ±60°） |
| 穀粒 | 金色 | コンケーブから落下 → グレインパン（後方へ） → チャッファ → シーブ → クリーングレインオーガ → エレベータ（右側、上昇） → ローディングオーガ → タンク内に落下・堆積 |
| 籾殻（チャフ） | 灰白 | シュー上でファンの風に乗って後方へ（速度 3〜6 m/s）→ 機体後方へ吹き出し |
| 2番（テーリング） | 橙 | チャッファ後端 → テーリングオーガ → グレインパンへ戻る |
| 排出 | 金色 | 排出オーガ先端 → 放物線落下（初速 1.5 m/s ＋重力）→ 地面／トレーラで消滅 |

### 7.2 実装
- 流れごとに `InstancedMesh` を1つ（粒子の形はそれぞれ低ポリの楕円体／短冊）。粒子数上限：全体で 8,000。
- 粒子は `{ pathId, t, offset }` を持ち、`t` を進めて経路上の位置を計算する。各区間の「速さ」は資料の値（ベルト速度・風速など）×再生倍率。
- 粒子の発生量は `groundSpeed × ヘッダ幅 × 収量係数` から決め、`separatorOn` が off なら脱穀以降の流れを止める。
- タンクの穀粒の山は粒子ではなく、`tankFill` に応じて高さが変わる**円錐形メッシュ**で表現（粒子はタンクに入った時点で消して山を高くする）。
- 排出時は `tankFill` を `排出速度 150 L/s ÷ タンク容量` の割合で減らす（14.1 m³ なら約 94 秒で空）。

## 8. 表示モードと UI

### 8.1 表示モード
| モード | 実装 |
|---|---|
| 外観 | 通常の表示 |
| X線 | 外板マテリアルを `transparent, opacity 0.15, depthWrite false` に切り替え、内部系を表示 |
| 断面 | `renderer.localClippingEnabled = true`、中心面 z=0 の Clipping Plane を外板・ケージ・タンクに適用（内部の回転体には適用しない）。切断面のキャップは stencil で描く |
| 分解 | サブシステムごとに `explodeOffset` ベクトルを持ち、0..1 で補間移動（例：ヘッダは +X に 3 m、タンクは +Y に 2 m、エンジンは −X・+Y） |
| ラベル | `CSS2DRenderer` で部品名（日本語／英語）を表示。クリックで部品を選択→説明パネルに資料の要約と出典リンク |

### 8.2 UI（lil-gui）
- 作業：エンジン／脱穀部／ヘッダ／排出 の ON・OFF、地速、ヘッダ高さ、リール高さ、操舵
- 機構：排出オーガ展開、タンクフラップ、ヘッダ切替（ドレーパー／コーン）、ロータの再生倍率

## 9. ジオメトリとマテリアル

### 9.1 作り方の方針
- **すべてコードで生成**（プロシージャル）。外部の3Dモデルファイルは使わない。寸法は `spec.ts`（§10）から読む。
- 外板：`Shape` → `ExtrudeGeometry`（面取り `bevelEnabled`）で側面シルエットを作り、左右に配置。
- 回転体：`CylinderGeometry`、らせんは `TubeGeometry`（オーガのフライト）、ベーンは細い Box を並べる。
- 繰り返し部品は `InstancedMesh`：リールのタイン、ナイフガード、ラスプバー、フィーダスラット、タイヤのラグ、コーンヘッドのロー、作物の茎。
- 静止部品は材質ごとに `BufferGeometryUtils.mergeGeometries` で結合し、ドローコールを減らす。

### 9.2 主要部品のつくり（概略）

| 部品 | 方法 |
|---|---|
| タイヤ | `LatheGeometry`（断面の輪郭を回転）＋ラグを InstancedMesh（V字＝R1W 相当、片側 23 本 × 2 列）。遠景 LOD ではラグを法線マップに |
| ホイールリム | Lathe ＋ 穴あきディスク（Shape の穴） |
| キャブ | フレームを細い Box で組み、ガラスは前面のみ曲面（`CylinderGeometry` の一部を切り出し）。`MeshPhysicalMaterial`（transmission 0.9 / roughness 0.05 / ior 1.5）。低品質設定では `MeshStandardMaterial` opacity 0.3 |
| グレインタンク | 外箱 Box ＋ V 底は Extrude（台形断面）。フラップは薄い Box をヒンジ Group に |
| 排出オーガ | 円筒＋ 先端エルボ（`TorusGeometry` の 1/4）＋ スパウト |
| ロータ | 芯は Cylinder、前端は円錐台＋三角羽根 3 枚、ラスプバーはらせん配置の Instanced Box |
| コンケーブ | 150° の円弧格子：細い Box（周方向の棒）× n と、円弧のリブ（Torus 片） |
| リール | 中心パイプ＋ スパイダアーム（Box）＋ バット 6 本（Cylinder）＋ タイン Instanced |
| ドレーパー | 平面＋スクロールテクスチャ（CanvasTexture で白いスラットを描く） |

### 9.3 マテリアル
- PBR（`MeshStandardMaterial`）を基本に、塗装は roughness 0.45 / metalness 0.2、黒い樹脂・ゴムは roughness 0.9。
- 環境光：`RoomEnvironment` を `PMREMGenerator` で IBL に。主光源に `DirectionalLight` ＋影（`PCFSoftShadowMap`、影を落とすのは外形の大きな部品だけ）。
- 色は `livery` オブジェクトにまとめる（本体・フレーム・ヘッダ・アクセント・ガラス）。

### 9.4 性能予算
| 項目 | 目標 |
|---|---|
| 三角形数 | 300k 以下（外観のみ 150k 以下） |
| ドローコール | 250 以下 |
| フレームレート | デスクトップ内蔵 GPU で 60 fps、粒子 8,000 時に 45 fps 以上 |
| 初回読み込み | 2 秒以内（モデル生成はすべてクライアント側） |
