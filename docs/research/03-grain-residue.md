# 穀粒搬送・グレインタンク・排出オーガ・残渣処理（後部）の資料

**調査上の制約:** この環境ではWebFetchが使えませんでした（deere.com、caseih.com、pami.ca のいずれもDNSエラー）。下の数値はすべて、WebSearchの検索結果に出た抜粋から取っています。メーカーのページはURLを確認できたものだけ載せています。根拠が写真観察や工学的な見込みのものは**推定**と書きました。

## 1. クリーングレインエレベータとローディングオーガ
- **構成（特許に記載あり）:** シュー（選別部）の下にある横送りオーガ → 機体側面のパドルチェーン式エレベータ → タンク上部のローディングオーガ（ファウンテン／バブルアップ）の順に搬送します。ローディングオーガの役目は「穀粒をタンク中央へ送ること」で、吐出口はタンク中央の上部にあります。JDのS680〜S790には「400bu パワーフォールディング用ローディングチューブ」という部品があり、タンクを伸ばすとローディングオーガも一緒に上がる構造だと考えられます。
- **位置は右側（推定）:** 排出オーガが左側にあるのは特許で確認できました（"swings out to the operator's left"）。エレベータが右側だと明記した資料は見つかりません。ただ、JD・Case IHの写真から見て、エレベータは右側の中央付近を、地上約0.8mからタンク上縁（約3.5m）まで縦に通っていると推定します。
- **寸法（推定）:** ケースの断面はおよそ0.25×0.35m、パドルの間隔はおよそ0.1mです。

- **エクステンション:** JDは「Power folding grain tank」「power folding bin extension」で、上部のフラップ（4辺）を油圧で開きます。自動で折り畳むタンクカバーはオプションとされていますが、機構の詳細は確認できませんでした。
- **外形:** X9の輸送高さは約13ft（3.96m、比較サイトの値）、輸送幅は3.5m未満です（Western Producer）。タンクの外形寸法そのものは公表値が見つかりませんでした。
- **外形の推定:** 容量16m³に盛り上がり分も考えると、タンクの外形は幅3.3m×長さ3.0m×深さ1.8m程度、フラップを開いた状態で＋0.5m程度と見ています。
- **タンク内の装備:** 底に横送り（クロス）オーガがあり、Case IHには油圧でクロスオーガを止める機能があります。のぞき窓はキャブ後面のガラスと、タンク前面の点検窓です（**推定**、仕様書では確認できず）。

## 3. 排出オーガ
- **長さ:**
  - JD S7：22.5 / 26 / 28.5 ft（6.9 / 7.9 / 8.7 m）
  - JD X9：26（27）/ 28.5 / 31 / 35 ft（7.9〜10.7 m）。35ftは「パワーフォールディング式」です。
  - NH CR（MY15）：26ft 2in（8.0m）／30ft 3in（9.2m）。CR8.90の中古車では27ft折り畳み式。
  - CLAAS：7種類、最長約12m。
  - Case IH 9250：28ft 9in（8.8m）。50ftヘッダ向けの延長折り畳み式＋可動スパウトもあります。
- **排出速度:**
  - JD S7 900：4.2 bu/s（150 L/s）
  - JD X9 1100：5.3 bu/s（186 L/s）
  - Case IH 9250：4.5 bu/s（約159 L/s）
  - CLAAS 8000：最大180 L/s（90 L/sまで下げられる）、18,000 Lを約100秒で排出
  - NH CR11：210 L/s（20,000 Lを約80〜95秒）
- **管径:** CLAASは330mmと420mm（XXL）。Case IH 250シリーズの延長部品はフライト径14in（356mm）です。
- **旋回角:**
  - LEXIONは105°（Koneviestiの記事。機種別の値ではない）。旧型は101°。
  - 7XLの先端部は長さ2.11mで、120°折れて機体後方に収まります。
- **スパウト:**
  - JDの可動スパウトはフットスイッチで前後に傾けられます。角度は公表されていません。
  - CLAASの可動スパウトは無段階で、穀粒の落下点を最大60cm動かせます。こぼれ止めのキャップ付きです。
- **到達距離:** 特許によると、吐出口はヘッダの端から横に1〜1.5m以上外に出る必要があり、10mヘッダなら横方向に6m以上の到達距離が要ります。
- **格納位置とピボット（推定、写真観察による）:** 格納時は機体の左側面に沿って後ろへ伸び、後端左のレストに載ります。ピボット（垂直オーガのタレット）はタンクの左前、キャブのすぐ後ろです。
- **吐出高さ（推定）:** 地上4.3〜5.0m。根拠は、グレインカートのオーガ高さが約13ft（4m）で、コンバインはそのカートの側壁を越えて排出する必要があることです。

## 4. 残渣処理
- **NH CR10 / CR11:** チョッパは固定刃60枚＋カウンタナイフ52枚。回転数は細断時3,000rpm、ウィンドロー時800rpm。スプレッダは油圧駆動の800mmインペラ2基です（global-agriculture.com）。
- **JD X9:** 「Wing Blade Wide-Spread, Fine Cut, 2-Speed Chopper with Integrated Chaff Spreader」で、散布幅は最大50ft（15.2m）。ナイフバンクと拡散方向をキャブから調整でき、Auto Swapで枕地に入ると方向を180°切り替えます。
- **CLAAS:** 旧型のSPECIAL CUT IIはナイフ108枚。8000シリーズは、反対向きに回る2つのロータでチョッパの細断物とチャフを全幅に散布します。
- **Case IH:** チョッパ／スプレッダの組み合わせが7種類あります。モードは「細断」「長わら散布」「ウィンドロー（チャフあり／なし）」の4つで、キャブから切り替えます。
- **ディスク回転数:** PAMIの旧JD機のデータでは、チャフスプレッダは水平ディスク2枚の逆回転で、500rpmを超えても散布幅は広がりませんでした。
- **チョッパ寸法（推定）:** ロータ径0.5〜0.6m、幅1.3〜1.6m。

## 5. 後部外観
- **ロータリースクリーン:** JDの特許によると、円形の回転スクリーンが機体側壁のパネル開口部（ヒンジ付き）に付いていて、側壁より少し内側にあります。その奥にラジエータ、オイルクーラ、エアコンのコンデンサが並びます。S7向けの「Rotary Screen Brush Kit」という部品もあります。
- **配置（推定）:** エンジンはタンクの後ろ上部に横置きで、スクリーンは片側の側面の上部後方、直径約1.2mです。どちら側かは確認できませんでした。
- **その他（推定）:** 後部のLEDライト、ハシゴ（左前方に主ハシゴ、後部に点検用のステップ）、後面下端のチョッパ／スプレッダのフードは、いずれも写真観察によるもので、根拠資料はありません。

## 6. アニメーション
| 対象 | 動き |
|---|---|
| タンクカバー | 4枚のフラップがヒンジ軸を中心に0→約110°開く（3〜5秒） |
| 排出オーガ | ピボットを中心にY軸回転0→105°（約8秒、推定）。LEXION 7XL型なら先端部が120°折れる |
| スパウト | X軸に±15°傾く（推定） |
| チョッパ | 3,000rpm（そのまま描画するとエイリアシングが出るので、見た目の回転数は5〜10rps程度に落とす） |
| スプレッダ | ディスク2枚が逆向きに回転 |
| エレベータ | パドルのUVスクロール |

## 7. 3D簡略化の提案
- **タンク:** BoxGeometry（底はExtrudeで台形にする）。フラップは薄いBoxで、ヒンジ軸を原点にしたGroupに入れる。
- **オーガ:** Cylinder（半径0.21m、長さ9m）をピボットGroupの子にする。スパウトは短いCylinderをX軸で回す。
- **穀粒の流れ:** InstancedMeshで500〜2,000粒（半径約2cmの楕円体）を出す。吐出口から初速1〜2m/s、重力をかけて放物線にし、タンクの上端か地面に着いたらプールに戻して再利用する。ほかの方法として、半透明のコーンに流れるテクスチャを貼る（低コスト）、またはその二つを組み合わせる。粒数は排出速度にあわせて「1フレームあたり(L/s÷k)個」で出す。
- **残渣:** Pointsまたは InstancedMesh の平たい板を扇形（後方±60°）に放出する。
