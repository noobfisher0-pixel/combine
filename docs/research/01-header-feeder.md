**ナイフ（カッターバー）**

## 4. フィーダハウス

**構造**［13］［14］
- 2〜4 本のチェーンにスラットを横向きに渡したコンベアです。
- 前側は浮動式のアイドラドラム（張力も調整）、後側は駆動スプロケットです。
- 中間にチェーンを支える床（ミッドフロア）があります。

**幅**
- Case IH 40 シリーズ：1,156 mm または 1,372 mm（45.5 / 54 in）、4 本チェーン・3 条構成［15］
- Case IH 7250/8250：49.5 in（1,257 mm）、4 本チェーン［16］
- JD S7 用の社外チェーン：スプロケット中心間 23-11/16 in（約 602 mm）［17］。これはスラット幅や全幅ではない可能性があります。

**スラット**
- 論文の試験条件は、スラットピッチ 153.6〜460.8 mm、スラット速度 2.0〜5.0 m/s でした。損失が少なかったのはピッチ 307 mm、速度 2.8〜3.6 m/s です［18］。
- チェーン張力は 18〜25 mm です（JD）［19］。

**長さ・傾斜角**：資料では確認できませんでした。
- **推定**：長さ 2.5〜3.0 m、作業時の傾斜 25〜35°。
- 根拠：前部ドラムが地上約 0.6 m、後部が車体のロータ入口（地上約 1.8〜2.0 m）にあることから見積もりました。

**フロントフェース**
- JD S700：前傾式フェースプレートで最大 17° の静的な前後調整ができ、油圧式の前後チルトもオプションで選べます［20］。
- JD X9：左右チルト（Contour Master）と前後チルトを備えた仕様が流通しています［21］。

**昇降**
- フィーダハウスと車体フレームの間に、左右 1 対（計 2 本）の油圧シリンダがあります。フィーダハウスは後端の横軸を中心に回動します［13］。
- シリンダの例：90 mm（3.5 in）（JD コーンヘッド用ガイド。ボアかサイズ表記かは不明）［19］
- 揚力の例：13,500 lb（250 シリーズ。ただし出典の信頼性は低め）［22］

**着脱**：フィーダ上部のサドルにヘッダの背板を掛け、下部をロックピンで固定し、駆動軸と油圧は一点で接続（シングルポイントカプラ）する方式です［9］［23］。

## 5. ヘッダ輸送トレーラ

- 全長 20〜52 ft（6.4〜15.8 m）の品揃えがあります［24］。
- 前 1 軸（Demco の資料では三輪状の前部）と、後 1〜2 軸の構成が一般的です［24］。
- 3D ではフレームを Box 数本、車輪を Cylinder で作り、ヘッダを横向きに載せる形で十分です。

  - ドレーパーベルトは黒いゴムに白いスラット、デバイダ（分草板）の先端は黒です。
  - ヘッダ端部に黄色の反射材があり、フィーダ上部に作業灯があります。

## 7. 3D 簡略化の提案

| 部品 | プリミティブ | 節約のポイント |
|---|---|---|
| ヘッダ背板・床・エンドシールド | Box と、断面を Extrude したもの（L 字・台形） | 1 メッシュに統合する |
| カッターバー・ナイフ | 薄い Box 1 本と、ガードの InstancedMesh（76 mm 間隔の三角柱） | ナイフは 1 本の Box を X 方向に正弦振動させる |
| リール | 中心軸は Cylinder、バットは細い Cylinder × 5〜6 本、スパイダアームは Box | タインは InstancedMesh（1 本 4〜6 tri）。遠景ではタインを省略する |
| ドレーパー | 平面に UV スクロールテクスチャ | 実際のベルト形状は作らない |
| オーガ | Cylinder と、TubeGeometry で作ったらせん状のフライト | 回転は mesh.rotation |
| コーンヘッド | ポイントは Cone または Extrude（尖った船底形）、ロー単位を InstancedMesh で複製 | チェーンはテクスチャのスクロール |
| フィーダハウス | Box 本体（中は空）、前面フェースは別 Group（チルト用） | 内部チェーンは見える開口部のみ InstancedMesh で表現する |
| 油圧シリンダ | 外筒・ロッドとも Cylinder | 2 点間で lookAt し、ロッド長を伸縮させる |
