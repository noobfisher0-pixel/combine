## 2. 残っているリスク・未確認事項

設計書 §13 の Q-1〜Q-7 のうち、実装の手戻りが大きいものです。

1. **Q-1 排出オーガの格納向き**：前向き格納と後ろ向き格納でピボット位置・全長・干渉相手が変わる。`stow` を切り替えられるようにし、M0 の検査で両方を通す。
2. **値の確度**：資料はメーカー仕様書 PDF を直接開けずに集めた。特にフィーダ長、ロータ軸高、エレベータ位置、エンジン寸法は E（推定）。公式資料や実機写真で確認できたら spec の確度を S に上げる。
3. **キャブの高さ 1.50 m**：干渉回避のために低めにした（D）。全高 4.00 を守りつつロータとの干渉を避けた結果で、見た目が低すぎる場合はロータ軸を下げる（シューの高さとの兼ね合い）か、全高の上限を見直す。
4. **断面キャップ**：閉じたメッシュを作る負担が大きい。M0 のスパイクで成立しなければ、断面は「キャップなし＋裏面を単色で描く」方式に落とす。
